# Momizza

## Momizza Restaurant Website built using Wordpress

Momizza is a simple Restaurant Website built in simple HTML, CSS, JS, PHP via Chatgpt with a layman Dashboard for user with role - Momizza Manager 

### Plugins Used:

- ACF Pro
- WooCommerce
- Razorpay for WooCommerce (1 Razorpay)
- Litespeed Cache
- All-in-One WP Migration and Backup + Unlimited Extension
